# Traceability: which test proves each requirement

Every acceptance criterion in [prd.md](prd.md) maps to the test that would fail if it broke. Each listed test was read, not only found by name.

- **Layer:** `unit` is plain `go test`. `envtest` is Ginkgo against a real API server (no kubelet, no CNI, no controllers such as garbage collection). `e2e` is Ginkgo on the k3d cluster with real traffic and rollouts.
- **Status tags** in the last column: **[fixed]** means the test was weaker than its name or the criterion and was strengthened in Phase 12. **[new]** means there was no test and Phase 12 added one. No tag means the existing test was already strong.
- Paths are relative to the repo root. Run everything with `make lint test test-e2e`.
